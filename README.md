# Лабораторная работа №4. Классификация

Требуется реализовать алгоритмы классификации: **k ближайших соседей (kNN)** и **метод опорных векторов (SVM)**.

## Часть 1. k ближайших соседей (kNN)

Реализовать классификатор `KNNClassifier` в файле `src/knn.py`.

Необходимо реализовать метод `predict`, выполняющий предсказание меток классов:

1. Вычислить расстояние от классифицируемого объекта до каждого объекта обучающей выборки с помощью переданной функции расстояния (`metric`).
2. Найти `k` ближайших соседей.
3. Определить класс голосованием:
   - `weights='uniform'` — голосование большинством (каждый сосед имеет равный голос).
   - `weights='distance'` — взвешенное голосование (вес каждого соседа обратно пропорционален расстоянию: `1 / d`).

Классификатор должен поддерживать произвольную функцию расстояния, передаваемую через параметр `metric`.

## Часть 2. Линейный SVM

Реализовать классификатор `LinearSVM` в файле `src/svm.py`.

Необходимо реализовать:

1. Метод `fit` — обучение модели методом стохастического градиентного спуска (SGD) с функцией потерь hinge loss и L2-регуляризацией:

$$L = \lambda \|w\|^2 + \frac{1}{N} \sum_{i=1}^{N} \max(0,\ 1 - y_i (w \cdot x_i + b))$$

2. Метод `decision_function` — вычисление значения решающей функции: $f(x) = w \cdot x + b$.
3. Метод `predict` — предсказание меток классов на основе знака решающей функции.

Метки классов при обучении должны быть в формате **{−1, +1}**.
